# LucasPropfirm — orchestration des shorts 15 s

> Périmètre : ce skill est la **carte du pipeline** et le **choix du concept**. Il ne redonne pas les règles créatives (voir `lucaspropfirm-short-description`) ni la procédure d'exécution (voir `lucaspropfirm-shorts-generation`).

## Contexte fixe
- Comptes : TikTok/IG @lucaspropfirm01, YouTube @lucasPropfirm2026.
- Univers : « marché financier vivant », faceless premium, bleu nuit + lime/or (détaillé dans `short-description`).
- Baselines : recalculer à chaque nouvel audit — ne jamais réutiliser d'anciennes stats comme actuelles.

## Étapes (idée → livrable)
1. **Choix du concept** — par recherche en ligne (ci-dessous).
2. **Contenu** — hook, script + CTA, prompt visuel 8 blocs, description IG : selon `short-description`.
3. **Validation utilisateur** — concept + script + prompt, puis coût crédits.
4. **Exécution** — narration → vidéo muette → montage voix → sous-titres → livrable : selon `shorts-generation`.
5. **Publication** — signature de fin + bloc de liens (ci-dessous).
6. **Mesure** — une variable testée par post (ci-dessous).

## Choix du concept — par recherche & analyse (aucun catalogue, aucune rotation)
- **Aucun template d'idées, aucun catalogue de concepts.** Le concept/angle de CHAQUE short vient d'une **recherche web + analyse de ce qui fonctionne** pour le sujet et la niche (formats viraux, hooks qui marchent, angles d'analyse technique, besoins du public FR).
- Pour chaque idée : rechercher et étudier AVANT de proposer — ce qui retient, ce qui convertit, ce qui différencie.
- **Jamais 2 vidéos identiques** ; le concept est choisi pour sa pertinence et son impact.
- **Règle de variété** : jamais 2 posts consécutifs de la même famille de plan ni du même patron de hook ; un concept = un angle éditorial adapté à l'idée analysée.
- Contraintes visuelles (anti-IP, zéro chiffre à l'écran, bougies en verre = identité autorisée) : voir `short-description`.

## Contrat de script (rappel — détail dans short-description)
UNE idée par vidéo ; 38-42 mots ; ≈15 s (durée verrouillée au TTS réel Julian, jamais change_voice) ; hook à 0-1,2 s compréhensible sans le son ; CTA unique fixe en fin. Zéro promesse de gains ; « jusqu'à -80 % » jamais garanti ; pas de nom de firme dans les vidéos éducatives.

**Interdits transversaux** : Limova sur compte trading, contenu EN sur le compte FR, 16:9, chandeliers génériques sans contexte, fausses interfaces broker, lifestyle richesse.

## Publication
- Signature de fin : logo LP rond lime (2 dernières s) + encart CODE LUCAS / lucaspropfirm.fr.
- Descriptions IG/TikTok/YouTube : accroche → contenu → **bloc de liens 10 lignes** (Phidias LUCAS, Discord, PropLog, 2 newsletters, Affiliation, Limova PROFILM30, Wisewand LUCAS10 FR/EN, Higgsfield lucas17). Format exact et texte dans `short-description`.

## Mesure
- Tester **UNE seule variable par post** ; seuils relatifs à la médiane du compte.
- Ne jamais comparer TikTok/IG/YT entre elles, ni prendre les vues pour organiques sans ratio like/vue.
